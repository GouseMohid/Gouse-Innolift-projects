About the Project

Product Review Sentiment Analyzer

A Flask and SQLite e-commerce analytics project powered by an Amazon review dataset.

Project Overview

This project imports product reviews from the supplied CSV, stores them in SQLite, trains a simple sentiment classifier from the labeled reviews, and provides a clean web interface for prediction and dataset browsing.

Technical Scope

Framework: Flask

Database: SQLite reviews and analyses tables

Model: Naive Bayes text classifier using dataset labels

A

CSV Import

Loads ProductId, reviewer details, helpfulness, summary, text, and sentiment labels.

B

Live Prediction

Scores new review text and saves each prediction with confidence.

C

Commerce Dashboard

Displays sentiment split, recent analysis history, and searchable review records.
