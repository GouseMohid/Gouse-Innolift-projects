About the Project

Student Registration System

A Flask template-rendering project designed for college student administration.

Project Overview

This project creates the frontend structure for a student registration portal using Flask, HTML, and CSS. It demonstrates route handling, template rendering, reusable navigation, professional page design, and dummy student record presentation.
