Platform Overview

AI-powered product review intelligence

ReviewPulse AI demonstrates how a Flask application can transform raw customer feedback into measurable sentiment analytics and operational insight.

Project Overview

From academic classifier to business-ready analytics workflow

The application imports e-commerce review data, stores it in SQLite, trains a lightweight text classifier, and exposes a polished interface for prediction, browsing, and sentiment monitoring.

Technology Stack

Backend: Flask with Jinja templates

Database: SQLite reviews and analyses tables

Model: Naive Bayes sentiment classifier

Frontend: Responsive HTML, CSS, and lightweight JavaScript

01

Import Reviews

Load product IDs, summaries, helpfulness scores, review text, and sentiment labels from the dataset.

02

Prepare Text

Tokenize review content, remove common stop words, and build a vocabulary for classification.

03

Predict Sentiment

Score submitted reviews against positive and negative language patterns learned from the dataset.

04

Store Insights

Save prediction history with confidence values for dashboard visibility and later review.

AI Prediction Process

How the model turns text into a business signal

1. Review Text: The user submits product feedback from the analyzer form.

2. Vectorization: The saved TF-IDF pipeline converts text into ML features.

3. Prediction: The classifier predicts positive or negative sentiment.

4. Output: The app displays sentiment, confidence, and suggested insights.
