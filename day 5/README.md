# Product Review Sentiment Analyzer - E-commerce

Current scope: **M1 only**.

## M1: Download, Load, Clean, Explore

This step loads up to 10,000 Amazon reviews, cleans the review text using NLTK stopwords, and explores the rating/sentiment distribution.

## Folder Structure

```text
Gouse-Innolift-projects/
|-- data/
|   |-- amazon_reviews.csv              full 10K dataset goes here
|   |-- amazon_reviews_sample.csv       fallback demo dataset
|   |-- amazon_reviews_m1_cleaned.csv   generated by M1
|-- model.py                            M1 main file
|-- train.py                            training entry point for later milestone
|-- predict.py                          saved-model prediction file for later milestone
|-- requirements.txt
|-- README.md
```

## How To Run M1

```powershell
pip install -r requirements.txt
python model.py
```

## What `model.py` Does

- Loads `data/amazon_reviews.csv` if available.
- Falls back to `data/amazon_reviews_sample.csv` for demo execution.
- Prints dataset shape, first rows, and column dtypes.
- Cleans review text by lowercasing, removing HTML/URLs/punctuation/numbers, and removing NLTK English stopwords.
- Prints null counts after cleaning.
- Prints rating distribution.
- Converts ratings into sentiment labels:
  - 1-2: Negative
  - 3: Neutral
  - 4-5: Positive
- Saves cleaned M1 output to `data/amazon_reviews_m1_cleaned.csv`.

## Dataset Columns

Supported review text columns:

```text
review, review_text, text, content, summary
```

Supported rating columns:

```text
rating, score, stars
```
